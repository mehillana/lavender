
Changelog — Lavender v8.0.0 (v8chaufa)


 — 2026-10-17


🍚 Added: Mangosoft & chaufa Engine

• Introducing Mangosoft: The new decentralized, fully local intelligence ecosystem built right into Lavender.
• chaufa-8 Model (Fast & Focused): A lightweight local model optimized for instant, single-action execution (add, move, or cancel events in milliseconds).
• chaufa-8-pro Model (High Power): A high-performance local engine capable of handling up to 12 complex steps in a single message across multiple modules.
• Live Bidirectional Interaction: A chat interface that updates the visual calendar grid in real time as actions occur ("Talk to your calendar. Watch it move.").
• Three-Step Reasoning Flow: Implementation of the local execution pipeline: Understand (intent splitting), Plan (safe tool queuing), and Apply Live (visual grid mutation).
• One-Tap Undo: A global revert feature to instantly undo any multi-step chain of changes generated by the engine.

📂 Added: Suite Expansion (Multi-App Ecosystem)

• Contacts Module: A dedicated local directory to manage people, linking birthdays, anniversaries, and personal details directly to your calendar grid.
• Dietary Module: An integrated nutritional planner accessible from the top navigation bar to manage meal schedules and logging.
• Diary Module: A personal mood and daily logging tracker with natural syntax support (e.g., log mood happy).

🔒 Security & Privacy

• 100% Local Processing: The natural language processing for both chaufa-8 and chaufa-8-pro runs entirely within the user's browser.
• Zero-Cloud Guarantee: No accounts, no servers, no ads, and no data tracking. Your calendar, contacts, and diary data never leave your local device.
